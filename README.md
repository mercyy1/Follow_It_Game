# 🎮 Follow It — C# Windows Forms Game

**Follow It** is a fun and interactive memory game built with C# and Windows Forms. The objective is simple: follow the visual cues and click the right cells in the correct sequence. Ideal for practicing logic, timing, and pattern recognition.

---

## 🚀 Features

- 🧠 Memory-based gameplay
- 🎨 Simple grid-based interface
- 🕹️ Mouse interaction to select cells
- 🔁 Replay and reset functionality
- 🧰 Structured object-oriented code (Player, Cell, etc.)

---

## 🛠️ Built With

- C# (.NET Framework)
- Windows Forms (WinForms)
- Visual Studio

---

## 🧪 Getting Started

### Prerequisites

- Windows OS
- Visual Studio (2022 or later)

### Running the Game

1. Clone the repository:
   ```bash
   git clone https://github.com/yourusername/Follow-It-Game.git
   ```
2. Open FollowIt.sln in Visual Studio.

3. Press F5 or click Start to run.
